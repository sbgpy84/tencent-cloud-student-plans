## 2核2G 和 2核4G 怎么选？

看你是否需要同机跑数据库。只跑一个 WordPress 或几个练手脚本，2核2G 足够；要同时开 MySQL、后端服务和 Redis，4G 内存更稳。

- **轻量 2核2G**：适合第一次接触云服务器的人。装宝塔面板、跑静态站、做 Python 爬虫练习、学 Linux 命令，资源都够。轻量产品有简化管理面板，上手比标准 CVM 省事。
- **轻量 2核4G**：多出的 2G 内存主要用来分担数据库和容器开销。Jupyter Notebook 跑数据处理、Docker 起两三个容器、Java 服务编译，2G 容易吃紧，4G 能少折腾。
- **CVM 2核4G**：需要自定义 VPC、挂负载均衡、连接云数据库，或者老师明确要求用标准 CVM 做实验时选它。轻量是套餐式简化产品，CVM 是完整版云服务器，功能边界不一样。

不确定选哪款的学生，多花时间比较内存，一般不会错。
